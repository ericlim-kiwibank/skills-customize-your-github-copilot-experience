

# 📘 Assignment: Games in Python – Hangman

## 🎯 Objective

Build a classic Hangman game in Python to practice string manipulation, loops, conditionals, and user input.

## 📝 Tasks

### 🛠️ Task 1: Set Up the Game

#### Description
Create a Python program that sets up the basic structure for a Hangman game.

#### Requirements
Completed program should:

- Define a list of possible words
- Randomly select a word for the player to guess
- Display the word as blanks (e.g., _ _ _ _)

### 🛠️ Task 2: Implement Game Logic

#### Description
Add the main game loop to handle user guesses and track progress.

#### Requirements
Completed program should:

- Accept letter guesses from the player
- Reveal correct letters in their positions
- Track and display incorrect guesses remaining
- End the game with a win or lose message

---
**Skills practiced:** String manipulation, loops, conditionals, random selection
