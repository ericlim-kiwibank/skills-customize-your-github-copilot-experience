# 📘 Assignment: Building REST APIs with FastAPI

## 🎯 Objective

Learn how to create a simple REST API using the FastAPI framework in Python. You will design endpoints, handle requests, and return JSON responses.

## 📝 Tasks

### 🛠️ Task 1: Set Up FastAPI Project

#### Description
Set up a new Python project and install FastAPI and Uvicorn. Create a basic FastAPI application that runs a web server.

#### Requirements
Completed program should:

- Have a `main.py` file with a FastAPI app
- Run the server using Uvicorn
- Display a welcome message at the root endpoint (`/`)

### 🛠️ Task 2: Create REST Endpoints

#### Description
Add endpoints to your FastAPI app to handle basic CRUD operations for a simple resource (e.g., items or users).

#### Requirements
Completed program should:

- Implement GET, POST, and DELETE endpoints for your resource
- Accept and return JSON data
- Handle errors gracefully (e.g., resource not found)

---
**Skills practiced:** Python web development, REST API design, FastAPI basics, JSON handling
